# LabSafe - Front-End

Aplicação para treinamento em segurança nos laboratórios

## Objetivo

Desenvolver um sistema web de treinamento em segurança nos laboratórios, reforçando o conhecimento do aluno e verificar se ele realmente tem a capacidade de entrar em laboratórios.

## Tecnologias utilizadas

- React
- TypeScript
- Tailwind CSS
- Lucide React
- React Router DOM

## Como executar o projeto

### 1. Clonar o repositório
```bash
git clone https://github.com/goncalvesjv2/labsafe-frontend
```

### 2. Acessar o projeto
```bash
cd labsafe-frontend
```

### 3. Instalar as dependências 
```bash
npm install
```

### 4. Rodar o projeto
```bash
npm run dev
```
